# Product & User Requirements Documentation Overview

Welcome to the product requirements and feature documentation for **Grahvani**. Grahvani is designed as a high-precision, AI-augmented Vedic astrology SaaS application tailored for India-first users and a growing global audience.

---

## 1. Product Vision & Strategy

Grahvani bridges the gap between **ancient astrological precision** and **modern AI accessibility**:
- **Deterministic Ephemeris Accuracy**: Powered by Swiss Ephemeris (`pyswisseph`) to eliminate calculation errors.
- **Evidence-Grounded AI**: Grounded RAG architecture ensuring interpretations directly cite authentic classical scriptures (*Brihat Parashara Hora Shastra*, *Saravali*, *Phaladeepika*).
- **India-First UX & Accessibility**: Native mobile Flutter client supporting multilingual interfaces, local timezones, and UPI recurring payments.

## 2. Target User Personas

| Persona | Demographics / Profile | Primary Needs & Pain Points | Key Grahvani Features Used |
| :--- | :--- | :--- | :--- |
| **Pooja (The Daily Seeker)** | Gen-Z / Millennial, 24-35, Urban India | Wants quick, authentic daily horoscopes, career guidance, and plain-language AI answers. Tired of generic zodiac apps. | Daily Horoscope, Grounded AI Chat, Matchmaking (Kundali Milan). |
| **Rajesh (The Traditional Astrologer)** | Professional Astrologer, 40-60, India/NRI | Requires arcsecond planetary accuracy, D1-D60 divisional charts, customizable ayanamsas, and downloadable high-res PDF charts. | D1-D60 Kundali, Vimshottari Dasha, White-labeled PDF Export, Custom Ayanamsa. |
